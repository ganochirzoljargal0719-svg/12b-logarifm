ЛОГАРИФМ

12-р анги • Онол, чанар, жишээ бодлого, интерактив сорил

1. Логарифмын үндсэн ойлголт

Логарифм нь зэрэгт дэвшүүлэх үйлдлийн урвуу үйлдэл юм. logₐ b = x гэдэг нь aˣ = b гэсэн утгатай.

logₐ b = x ⇔ aˣ = b

Нөхцөл: a > 0, a ≠ 1, b > 0.

Жишээ: log₂ 8 = 3, учир нь 2³ = 8.

2. Логарифмын үндсэн чанарууд

logₐ 1 = 0
logₐ a = 1
logₐ (xy) = logₐ x + logₐ y
logₐ (x/y) = logₐ x − logₐ y
logₐ (xʳ) = r · logₐ x
logₐ b = (log꜀ b) / (log꜀ a)

Эдгээр чанарт логарифмын аргументууд эерэг байх шаардлагатай.

3. Бодох аргачлал

  1. Логарифмын суурь эерэг бөгөөд 1-тэй тэнцүү биш эсэхийг шалгана.
  2. Аргумент эерэг байх нөхцөлийг бичнэ.
  3. Боломжтой бол логарифмыг зэрэгт хэлбэрт шилжүүлнэ.
  4. Ижил суурьтай логарифмын чанарыг хэрэглэнэ.
  5. Олсон хариуг анхны нөхцөлд орлуулж шалгана.

4. Жишээ бодлогууд

Жишээ 1. log₃ 81 = x

3ˣ = 81 = 3⁴ тул x = 4.

Жишээ 2. log₂ x = 5

x = 2⁵ тул x = 32.

Жишээ 3. log₅ 25 + log₅ 5

2 + 1 = 3.

Жишээ 4. log₂ x + log₂ 4 = 5

log₂(4x) = 5 → 4x = 32 → x = 8.
